# Client Interview Prep Questions

## Tier 1

### Java & Spring

1. What's the difference between an interface and an abstract class, and when would you pick one over the other?
2. What's the difference between `==` and `.equals()` in Java?
3. What's the difference between checked and unchecked exceptions?
4. When would you use a `List`, a `Set`, or a `Map`?
5. What are dependency injection and inversion of control, and how does Spring use them?
6. What's the difference between `@Component`, `@Service`, `@Repository`, and `@Controller`?
7. What does Spring Boot add on top of the Spring Framework?
8. What does Spring Data JPA give you when you extend `JpaRepository`?
9. What does `@Transactional` do, and why would you use it?

### SQL

10. Explain the different types of joins (inner, left, right, full).
11. What's the difference between `WHERE` and `HAVING`?
12. What are primary keys and foreign keys, and how do they relate tables?
13. What is normalization, and why does it matter?
14. What is an index, and what's the trade-off of adding one?
15. What does ACID mean in the context of database transactions?

### REST

16. What makes an API RESTful?
17. Walk through the main HTTP methods. Which are idempotent?
18. What's the difference between `PUT` and `PATCH`?
19. What do these status codes mean: 200, 201, 400, 401, 403, 404, 500?
20. How would you build a REST endpoint in Spring? What's the difference between `@PathVariable` and `@RequestParam`?

## Tier 2

### React

21. What's the difference between props and state?
22. What is `useEffect` used for, and what does its dependency array control?
23. Why does React need a `key` when rendering a list?

### JavaScript / TypeScript

24. What's the difference between `var`, `let`, and `const`?
25. What's the difference between `==` and `===`?
26. What is a Promise, and how does `async`/`await` relate to it?
27. What does TypeScript add over JavaScript?

### HTML / CSS

28. Explain the CSS box model.

## Tier 3

29. What are the trade-offs between a microservice architecture and a monolith?
30. When would you choose a NoSQL database over a relational one?
31. What's the difference between a container and a virtual machine?
32. In Python, what's the difference between a list and a tuple?
33. How have you used AI tools in your development work, and what are their limitations?
